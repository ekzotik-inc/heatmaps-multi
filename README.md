# 🗺️ Heat Map · Multi-user

**Многопользовательская платформа карт-аналитики спроса для торговых точек.**

Любой сотрудник регистрируется, создаёт изолированные проекты и загружает
свои данные. Внутри проекта строятся тепловые слои спроса, рекомендации по
открытию новых точек и командная работа с ролями.

---

## 🎯 Что делает платформа

- **Регистрация и аккаунты** — у каждого пользователя свой логин.
- **Изолированные проекты** — каждый проект принадлежит владельцу; данные
  разных проектов и пользователей не пересекаются.
- **Командная работа** — владелец приглашает участников по логину с ролями
  `owner` / `editor` / `viewer`.
- **Свои данные** — никаких вшитых датасетов: проект начинается с чистого
  холста, данные загружаются из Excel/CSV.

---

## ✨ Возможности

### 🔥 Тепловые слои спроса
- Любое число пользовательских слоёв — создаёшь и загружаешь данные из Excel/CSV.
- При наложении слои **смешиваются**: зоны пересечения спроса видны сразу.
- 6 научных цветовых палитр (Viridis, Inferno, Turbo и др.) + свой цвет.
- Настройка яркости, прозрачности, размера пятна и режима наложения.

### 📍 Рекомендации «где открыть точку»
- Алгоритм находит зоны **высокого спроса вне покрытия** существующих точек.
- **Слой-ориентир** выбирается пользователем (например, действующие ТТ).
- Без ориентира — ранжирование по спросу; с ориентиром — исключаются
  уже покрытые зоны.
- Регулируемый радиус покрытия и количество зон.
- Экспорт рекомендаций в **Excel**.

### 👥 Командная работа и роли
| Действие | owner | editor | viewer |
|---|:---:|:---:|:---:|
| Просмотр карты | ✓ | ✓ | ✓ |
| Менять слои, данные, настройки | ✓ | ✓ | — |
| Удалить/переименовать проект | ✓ | — | — |
| Управлять участниками | ✓ | — | — |

### 🕒 История и надёжность
- **История изменений** — последние 20 сохранений с возможностью отката.
- **Оптимистичная блокировка** — защита от перезаписи при одновременном
  редактировании (конфликт версий → подсказка перезагрузить).
- **Real-time уведомления** (SSE) — когда коллега обновил карту.
- **Экспорт/импорт проекта** в ZIP — перенос между серверами.
- **Дублирование проекта** — как шаблон.

### 🛡 Администрирование
- Первый зарегистрированный пользователь становится админом.
- Управление пользователями, сброс паролей, выдача прав.

## 🛠️ Технологии

| Компонент | Что используется |
|-----------|------------------|
| Карта | [Leaflet](https://leafletjs.com/) + [Leaflet.heat](https://github.com/Leaflet/Leaflet.heat) |
| Подложка | CARTO Voyager |
| Excel / CSV | [SheetJS](https://sheetjs.com/), [PapaParse](https://www.papaparse.com/) |
| Фронтенд | Чистые HTML / CSS / JS — без сборки |
| Бэкенд | Node.js + Express |
| Хранение | SQLite ([better-sqlite3](https://github.com/WiseLibs/better-sqlite3)) |
| Авторизация | bcrypt + cookie-сессии |

## 🚀 Запуск

```bash
cd server
npm install
node server.js
```

Открыть **http://localhost:3001** — фронтенд раздаётся тем же сервером
(один origin, авторизация через httpOnly-cookie, без CORS-настроек).

База `heatmaps.db` создаётся автоматически при первом старте.

### Конфигурация
Опционально — `server/.env`:
```
PORT=3001
```

## 📝 Примечания

- Рекомендации носят аналитический характер и зависят от выбранного
  слоя-ориентира и параметров покрытия.
- Блок «Доход Ташкента» оставлен в «спящем» режиме и появляется только
  при наличии соответствующих данных в проекте.
